# Mini-Projeto-POO
Plataforma de apoio ao estudo em C# com Windows Forms: sessões de estudo com XP, metas semanais e alertas ao responsável, integrada a um backend REST local com MySQL. Projeto da Oficina PBL (Aula 9) de Programação Orientada a Objetos.


FecapStudy

Mini-projeto de Programação Orientada a Objetos em C# e Windows Forms. O discente registra sessões de estudo (Pomodoro, Exercícios ou Leitura), ganha XP e acompanha o progresso da meta semanal. O responsável recebe alertas por e-mail, WhatsApp ou painel.

A tela se comunica com um backend local (http://localhost:5080) por API REST, gravando as sessões em MySQL. Se o backend estiver desligado, o app continua funcionando em memória.

Conceitos de POO aplicados: abstração, encapsulamento, classes abstratas e herança, polimorfismo (dinâmico e estático), interfaces, associação, agregação, composição e dependência.

Tecnologias: C#, .NET 8, Windows Forms, HttpClient, System.Text.Json.
